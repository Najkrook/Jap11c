## 💡 Studietips inför tentan

1. **Partikelstavning vid hälsningar**:
   - `こんにちは` (konnichiwa) och `こんばんは` (konbanwa) slutar med hiragana **は** (ha), inte わ.
2. **Långa vokaler i Hiragana**:
   - `おとうさん` (far) och `おとうと` (lillebror) samt `こうこう` (gymnasium) stavas med **う** för det långa o-ljudet.
   - `おねえさん` (storasyster) stavas med **え**.
   - `おかあさん` (mor) och `おにいさん` (storebror) stavas med **あ** respektive **い**.
3. **Kosoado-systemet (Pekorden)**:
   - **Ko-** (これ, この, ここ): Nära talaren.
   - **So-** (それ, その, そこ): Nära lyssnaren.
   - **A-** (あれ, あの, あそこ): Långt från båda.
   - **Do-** (どれ, どの, どこ): Frågeord (vilken / var).
   - Kom ihåg skillnaden: `これ` står för sig självt som pronomen (*"detta"*), medan `この` måste åtföljas av ett substantiv (*"den här boken"*).
